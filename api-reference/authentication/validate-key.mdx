---
title: "Validate key"
openapi: "GET /authentication/validate_key"
---

Validates TMDB API credentials using an API key (passed as the `api_key` query parameter) or API Read Access Token (passed as a Bearer token in the `Authorization` header).

**Note:** This endpoint does not require any additional parameters beyond the authentication credentials.

## API key authentication

Pass your TMDB API key using the `api_key` query parameter.

```bash
curl --request GET \
  --url 'https://api.themoviedb.org/3/authentication/validate_key?api_key=YOUR_API_KEY'
```

## Bearer token authentication

Pass your TMDB API Read Access Token in the `Authorization` header as a Bearer token.

```bash
curl --request GET \
  --url https://api.themoviedb.org/3/authentication/validate_key \
  --header 'Authorization: Bearer YOUR_ACCESS_TOKEN'
```

## Common use cases

* Verify credentials during application setup.
* Confirm that an API key or access token is valid.
* Test API connectivity before making other authenticated requests.
* Troubleshoot authentication or configuration issues.
