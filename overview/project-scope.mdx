## Scope

This guide tests and documents 52 TMDB API endpoints across authentication, account, search, discover, movies, networks, and certifications.

The documentation covers parameters, authentication requirements, practical use cases, response schemas, error responses, and troubleshooting guidance based on testing during implementation.

## Method

Every endpoint in this guide was tested against the live TMDB API. Parameters and authentication requirements were verified through actual requests, and response schemas were validated against observed API responses.

Each documented error was reproduced during testing to verify the API’s actual behavior. Where the error message or response body provided more useful information than the HTTP status code alone, the documentation included those details and explained how to resolve the issue.

## How the reference is structured

<AccordionGroup>
  <Accordion title="Descriptions explain, they do not duplicate">
    The endpoint descriptions focus on what the endpoint does, when to use it, and any important behaviour. Field-level details are documented in the response schema.
  </Accordion>
  <Accordion title="Field documentation lives on the schema">
    The response fields are documented alongside their types and descriptions, so developers can understand a response without searching elsewhere in the guide.
  </Accordion>
  <Accordion title="Errors sit with the response they describe">
    The endpoint-specific errors are documented alongside the corresponding responses, with likely causes and troubleshooting steps.
  </Accordion>
  <Accordion title="Shared guidance is centralised">
    Every information that applies across multiple endpoints—such as authentication, common parameters, or error handling—is documented once and linked from the relevant pages.
  </Accordion>
</AccordionGroup>

## Conventions

| Convention | Meaning |
| --- | --- |
| `{variable}` | A path parameter that you replace with a resource value, such as `{movie_id}` |
| `{{variable}}` | A variable referenced by the API client, such as `{{base_url}}` |
| **Required** | The request fails without this value |
| Session ID | A v3 session identifier created through the TMDB authentication workflow |

## Out of scope
This guide does not currently cover:
- TV season and episode endpoints.
- The full v4 list management API.
- Image delivery and sizing beyond the configuration values required to construct an image URL.
