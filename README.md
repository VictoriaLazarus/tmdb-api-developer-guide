# TMDB API Developer Guide

A comprehensive API documentation project covering TMDB endpoints, authentication workflows, request and response examples, OpenAPI specifications, Swagger documentation, and a Mintlify developer portal.

## Project Goals

- Document approximately 70 TMDB API endpoints
- Demonstrate API testing and analysis
- Showcase docs-as-code workflows
- Create OpenAPI specifications
- Generate Swagger documentation
- Publish documentation with Mintlify
