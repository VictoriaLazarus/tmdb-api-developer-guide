The Movie Database (TMDB) API is a RESTful web service that lets you search for content, retrieve metadata, manage user data, and build applications around movies and television. The API returns data in JSON and uses standard HTTP methods such as `GET`, `POST`, and `DELETE`.

This guide walks you through the API from setup and authentication to making requests, reading responses, and handling errors. It also provides runnable examples and field-level response schemas for the documented endpoints.

## Base URL

All requests in this guide are made against the TMDB v3 API:

```
https://api.themoviedb.org/3
```

## What this guide covers

This guide documents 52 TMDB endpoints across seven groups.

| Group | Endpoints | What it does |
| --- | --- | --- |
| [Authentication](/api-reference) | 8 | Request tokens, user sessions, and guest sessions |
| [Account](/api-reference) | 11 | Account details, favorites, watchlists, ratings, and lists |
| [Search](/api-reference) | 7 | Text search across movies, TV, people, collections, and keywords |
| [Discover](/api-reference) | 2 | Filtered and sorted browsing without a search term |
| [Movies](/api-reference) | 19 | Details, credits, images, videos, reviews, providers, and ratings |
| [Networks](/api-reference) | 3 | Television network details, images, and alternative names |
| [Certifications](/api-reference) | 2 | Movie and TV content rating systems by country |

Every endpoint page includes the parameters, the schema of each field in the response, a runnable request, and the errors that endpoint returns along with how to resolve them.

## How to read an endpoint page

<Steps>
  <Step title="Read the summary and use cases">
    Start with the overview to understand what the endpoint does, what it’s useful for, and when you might use it.
  </Step>
  <Step title="Check authorization">
    Review the **Authorizations** panel to see which authentication method the endpoint uses, such as a Bearer token, API key, or session ID.
  </Step>
  <Step title="Review the parameters">
    Check the required and optional parameters before sending the request. Each parameter includes a description to help you understand what to provide.
  </Step>
  <Step title="Test the endpoint">
    Enter the required values in the API console and send the request to see a live response.
  </Step>  
  <Step title="Expand the response schema">
    Expand the response schema to see the fields the endpoint returned. Each field is documented inline, so you know what a value represents without leaving the page.
  </Step>
  <Step title="Open the error tabs">
    Open the error tabs to see the status codes the endpoint can return, along with likely causes and endpoint-specific guidance for resolving them.
  </Step>
</Steps>
